# Admin Visual Rebuild — Deferred Requirements

These items are explicitly out of scope for Admin Batch 2 and remain future work.

See also [`DEPARTMENT-LANDING-DEFERRED.md`](./DEPARTMENT-LANDING-DEFERRED.md) for taxonomy/category image requirements.

## A. Product taxonomy assignment

Admin Product create/edit must eventually require a valid **leaf-category** assignment. Selecting a leaf should derive ancestors (Department → Group → Leaf).

## B. Category management

Admin controls for taxonomy/category content (names, sort, activation beyond product-driven availability).

## C. Category card images

Admin upload for Department Landing category card images.

## D. Department / mega-menu editorial image

Separate from category card images — large editorial image per department mega menu.

## E. Multilingual content

Hebrew/English optional per field; neither language individually mandatory.

## Additional future UX (from client references, not implemented)

- Global admin search (⌘K)
- Unified notification center with badge counts
- Project cover/thumbnail images on projects list
- Product library pagination (if catalog grows very large)
